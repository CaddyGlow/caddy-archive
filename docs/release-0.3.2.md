# caddy-archive 0.3.2

This release includes the fixture qualification repairs described in
[0.3.1](release-0.3.1.md) and the Windows directory timestamp handle fix.

0.3.2 includes the fix qualified by the complete host, Windows and browser CI.

All four workspace crates move together to 0.3.2. The published MSI backend
versions and the registry package-core compatibility bridge are unchanged.
